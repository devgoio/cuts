# Cutpas Support

[简体中文](#cutpas-技术支持) · [Privacy Policy](PRIVACY.md)

Cutpas runs in the macOS menu bar and requires macOS 26 or later. No account is needed.

- **Capture:** Choose **Region Screenshot** from the Cutpas menu, or use **Option–2**. Drag a region. For a longer page, choose **Scrolling Screenshot**, drag over a scrollable window, scroll manually, then choose **Finish**.
- **Clipboard and timers:** **Control–Option–V** opens clipboard history in the App Store edition. Restore an item and paste it with **Command–V**. **Option–T** creates a timer. You can change these shortcuts in Settings.
- **Language:** Open **Settings → General → App Language**. Choose English, Simplified Chinese, or System Default. Quit and reopen Cutpas to apply the change.
- **Troubleshooting:** If capture fails, check Cutpas in **System Settings → Privacy & Security → Screen & System Audio Recording**. If a shortcut conflicts with another app, assign a different chord. For translation, follow the macOS prompt to install any needed language packs.

Email [lm@usev.cn](mailto:lm@usev.cn) for help. Include your macOS version, Cutpas version, and steps to reproduce the problem. Do not send private screenshots or clipboard content.

# Cutpas 技术支持

[隐私政策](PRIVACY.md)

Cutpas 在 macOS 菜单栏运行，需要 macOS 26 或更新版本，无需登录。

- **截图：** 从菜单选择「区域截图」或按 **⌥2**，拖动选区。长页面可选「滚动长截图」，框选后手动滚动，再点「完成」。
- **剪贴板与计时：** App Store 版按 **⌃⌥V** 打开剪贴板历史，恢复条目后用 **⌘V** 粘贴。按 **⌥T** 新建计时。快捷键可在设置中修改。
- **切换语言：** 打开「设置 → 通用 → 应用语言」，选择简体中文、English 或跟随系统，退出并重新打开 Cutpas。
- **排障：** 截图不可用时，在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」检查 Cutpas 权限；快捷键被占用时可换一个组合。翻译提示缺少语言包时，可按 macOS 的提示下载。

请发邮件至 [lm@usev.cn](mailto:lm@usev.cn) 寻求帮助。请附 macOS 和 Cutpas 版本及复现步骤，不要发送私密截图或剪贴板内容。
